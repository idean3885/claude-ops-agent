# Spec: AI 티 SSOT 를 im-not-ai v2.3 와 정합

이슈: #153

## 배경

AI 티 분류 SSOT(`config/style-rules/base/ai-tells.md`)는 골격을 im-not-ai(MIT) humanize 분류 체계 v2.0.0 에서 차용했다. 업스트림이 v2.3.0 까지 진행되며 신규 패턴 33건, 심각도 재조정, 번역학 근거 문서(scholarship), 14지표 정량 스크립트(metrics_v2)가 추가됐다. 이 격차를 반영한다.

원칙: **정확도 우선, SSOT 비대화 최소화.** 우리 자체 추가분(K 카테고리, A-11/12, D-6~11 hook 확장)은 보존한다. 업스트림 ID 와 우리 ID 는 1:1 이 아니므로 **의미 기준**으로 매핑한다.

## 범위

업스트림 active 서브패턴을 의미 대조해 우리에 없는 것만 추린다. 새 ID 는 각 카테고리 다음 빈 번호로 이어붙인다. 일부는 새 ID 없이 기존 항목 처방 보강으로 반영해 비대화를 막는다.

### 2. 심각도 승급

| 우리 항목 | 현재 → 변경 | 근거 |
|---|---|---|
| A-2 `~에 있어서/있어` | S2 → **S1** | 업스트림 A-3 S1, 강등 이력 없음 |
| A-3 `~에 대해/관해` | S2 → **S1** | 업스트림 A-1 S1 |
| A-7 light verb `가지고 있다` | S2 → **S1** | 업스트림 A-7 S1 |
| A-6 영어 대명사 직역 | S2 → **조건부 S1** | 번역·요약·외부 AI 글 가공 맥락에서만 S1, 자생 작성문은 S2 유지 (v2.3 실증: 자생 산문은 인간이 대명사 더 씀) |

승급분은 **forbidden-words hook 미등록** (방침 확정). SSOT 검증 규칙으로만.

### 3. G-1 충돌 정합

우리 G-1(다중 완곡 → 단일 hedge 축소)과 업스트림의 추측 종결 남발 규칙은 표면 충돌이나 측정 차원이 다르다(밀도 vs 분포). G-3 를 "분포 편중"으로 신설하고, G-1 처방에 단서 한 줄(`~로 보인다`는 축소 도착점이나 문단 대부분을 덮으면 G-3 로 넘어가 단언 전환) + 상호 참조.

### 4. 정량 인프라

- **`config/style-rules/metrics/metrics-spec.md`** 신설: 14개 지표 정의 + 본진 패턴 연계 + `speculative` 플래그 표. base 미러 대상 아님.
- **`config/style-rules/metrics/tells_count.py`** 신설: baseline 의존 없는 순수 카운터만 추출(`change_rate`, `double_passive_count`, `double_particle_count`, `pronoun_density`, `have_make_literal_count`, 쉼표 계열, `antithesis_count`). "정확도 우선" 시 선택 실행. z-score·합성 지수는 baseline 부재로 제외.
- **`config/style-rules/references/scholarship.md`** 신설: 학술 근거 + PE1~15 체크리스트 축약 이식. base/ 아님(세션 예산 보호). `base/ai-tells.md` 각 신규 행은 `source_anchor` 로만 가리킴.
- **철칙 #4 실측화**: `change_rate` 함수로 변경률 30% 경고 / 50% 중단을 눈대중 대신 수치 판정.

### 5. content-verify 게이트 개편 (최소 침습)

4개 범주 골격 유지. 범주 4(가독성)를 "가독성 + AI 티 정량"으로 확장:

```text
### 범주 4. 가독성 + AI 티: {PASS|FAIL}
- 가독성 필수: N/M · 권장: N/M
- AI 티: S1 {n}건 · S2 {n}건 → 품질등급 {A|B|C|D}
```

등급 기준은 `ai-tells.md` 기존 정의 재사용. standalone 정밀 검증 시 `tells_count.py` 선택 호출로 눈대중 카운트 대체. inline 모드(content-write Phase 3)는 불변(핫패스 비용 회피). Phase 4 후 `change_rate` 게이트 신설.

## 강등 2건 (결정됨)

원칙: 업스트림(전문가·집단지성)은 거의 전적으로 신뢰해 최대 반영하되, 우리 고유 취향층(K 카테고리·forbidden-words hook·저자 톤)은 오염 방지 위해 보존한다.

1. **A-1 `~를 통해`**: SSOT 심각도 **S1 → S2** 강등(업스트림 v2.3 실증 수용). 단 forbidden-words hook 항목은 **저자 선호 표현으로 유지**: hook 매핑 표에서 근거를 "저자 선호 표현(비 S1)"으로 디커플링. 매 세션 주입되는 우리 취향층 보존.
2. **I-1 `것이다`**: **S1 → S2** 강등(hook 무관, 순수 분석 교정). 처방: 3회+ 반복만 교정.
