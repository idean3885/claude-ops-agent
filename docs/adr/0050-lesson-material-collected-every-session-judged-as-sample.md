# ADR-0050: 레슨 재료는 모든 세션에서 토큰 없이 수집하고, 판정은 상한 안에서 최근 세션부터 돌린다

- 상태: accepted
- 일시: 2026-11-27
- 관련: #1289, [ADR-0037](0037-lessons-judged-off-work-time-measured-by-accuracy.md)(작업 시간 밖 판정 · 정답률), [ADR-0047](0047-lesson-approval-opens-at-session-wrap-with-caps.md)(결정 4 의 만료 기점을 대체)

## 배경

| 사실 | 출처 |
|------|------|
| 설계는 「수집은 바로, 판정은 나중」이었으나 수집과 판정이 한 동작이었다. 하루 판정 상한(10세션)과 실행당 묶음(5세션)이 수집까지 막았다. | `scripts/lessons-judge.py` (변경 전) |
| 11/20 이후 끝난 세션 226개 중 판정 기록에 남은 것은 10개다. 사용자가 실패 기록을 매번 직접 챙겨야 했다. | #1289 (판정 기록 · 트랜스크립트 실측, 2026-11-27) |

목적은 판정 재료가 사람이 챙기지 않아도 빠짐없이 모이는 것이다. 판정은 늦어도 되지만 수집은 빠지면 되돌릴 수 없다. 트랜스크립트는 보관 기간이 지나면 지워진다.

## 결정

1. **수집과 판정을 나눈다.** 세션 시작 훅이 띄우는 분리 프로세스는 판정 전에 수집을 먼저 돈다. 수집은 모델을 부르지 않는다. 지난 수집 뒤 새로 끝난(조용한 시간 30분) 메인 세션을 상한 없이 훑어 세션마다 한 줄을 지표 폴더의 월 파일(`lessons-collect-YYYY-MM.jsonl`)에 남긴다.
   - 한 줄에는 세션 식별자 · 프로젝트 · 트랜스크립트 경로 · 세션 시각 · 답 수 · 사용자 발화 목록(발화마다 1500자까지)을 담는다.
   - 답 본문은 담지 않는다. 크기가 답 수만큼 커지고, 판정은 트랜스크립트가 남은 동안 원본을 읽는다.
   - 수정 시각이 같은 세션은 다시 쓰지 않는다. 이어 쓴 세션은 수정 시각이 바뀌어 한 줄을 더 쓴다. 이어 쓴 뒤의 발화도 빠지지 않고, 보고의 수집 세션 수는 트랜스크립트로 중복을 뺀다.
   - 판정용 자식 세션 · 서브에이전트 기록은 판정 대상 규칙과 같게 뺀다.
   - 지표 폴더는 이미 백업되므로 업로드 장치는 두지 않는다.
2. **판정은 하루 상한 안의 표본이다.** 상한(10세션)은 그대로 두고, 최근 세션부터 고른다. 트랜스크립트가 지워져 수집 기록만 남은 세션은 판정하지 않는다. 발화만으로는 교정을 어느 답에 붙일지 정할 수 없고, 입력 판이 하나 더 생겨 정답률 비교가 갈라진다.
3. **만료는 판정 시각부터 7일이다.** ADR-0047 결정 4 의 만료 기점(세션 시각)을 대체한다. 기한 7일과 자동 기각은 그대로다.
4. **판정은 빈 설정으로 실행한다.** 설정 출처 · MCP · 도구 · 스킬을 빼고 「JSON 한 줄만 출력」 한 줄짜리 시스템 프롬프트를 준다. 판정 지시문은 지금처럼 입력 앞에 붙인다.
5. **보고는 수집 세션 수를 함께 보인다.** 정답률 분모는 판정한 세션 기준 그대로다. 새 지표는 두지 않는다.

## 기각한 대안

| 대안 | 포기하는 것 | 얻는 것 | 기각 이유 |
|------|------------|---------|-----------|
| 판정 상한 제거(모든 세션 판정) | 비용 상한 | 수집 · 판정이 한 번에 | 하루 수십 세션을 판정하면 비용이 사용 한도를 갉아먹는다(ADR-0037). 재료만 모이면 판정은 표본으로 충분하다. |
| 만료 기한만 연장(세션 시각 기점 유지) | 없음 | 작은 변경 | 상한에 밀린 세션은 기한을 늘려도 판정 즉시 만료될 수 있다. 문제는 기한이 아니라 기점이다. |
| 수집 기록에 답 본문 포함 | 기록 크기 | 트랜스크립트가 지워져도 판정 가능 | 월 파일이 답 수만큼 커진다. 판정은 최근 세션부터라 트랜스크립트가 남아 있다. |
| 수집 기록의 발화만으로 판정 | 판정 정확도 | 지워진 세션도 판정 | 교정을 붙일 답이 없고, 입력 판이 갈라져 전후 비교가 깨진다. |
| `--bare` 로 판정 | 구독 인증 | 옵션 하나로 최소 실행 | OAuth 를 읽지 않아 판정이 돌지 않는다. |
| 수집 기록 전용 업로드 장치 | 장치 유지 비용 | 명시적 전송 | 지표 폴더는 이미 백업된다. |

## 결과

- 모든 끝난 세션이 토큰 없이 수집 기록에 남는다. 판정 상한이 수집을 막지 않는다.
- 판정 1회 고정 비용이 약 0.116달러에서 0.011달러로 준다(실측 1회).
- 늦게 판정한 세션도 7일 동안 승인 묶음에 오른다.
- 판정되지 않은 세션의 교정은 포기한다. 수집 기록은 남으므로 나중에 판정 방식을 바꿔도 재료가 있다.
- 세션 시작마다 분리 프로세스가 뜬다. 수집은 파일 목록과 새 세션만 읽는다.
