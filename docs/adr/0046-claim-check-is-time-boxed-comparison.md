# ADR-0046: 주장 검증 회차는 4분 안의 대조이고, 회차 상한은 2회다

- 상태: accepted
- 일시: 2026-11-20
- 관련: #1184, [ADR-0030](0030-checks-verify-claims-full-survey-is-manual.md)(결정 2 멈춤 조건의 「제로베이스 검토와 같음 · 3회」를 대체), #1066, #1163

## 배경

| 사실 | 출처 |
|------|------|
| 보안 · 셸 파서 작업의 회차가 11-19 이전 평균 3.0분 · 97k 토큰에서 회차당 10~36분 · 최대 313k 토큰으로 늘었다. 늘어난 회차는 검증자가 퍼징 · 차등 실험으로 반례를 끝까지 찾은 회차다. | #1184 Why |
| 6배 회차를 같은 입력으로 다시 돌리며 시간 제한만 건 시험은 원래 차단 2건이 있던 행을 「봤다(일부)」로 적고 차단 0건을 내, 지금 규칙에서는 통과로 기록된다. | #1184 Why |
| 작성자가 반례 형태 목록을 미리 내고 검증자는 그 목록만 대조하는 시험은 결함 2건을 차단하지 못했고, 목록 작성에 검증과 비슷한 비용이 들었다. | #1184 Why |
| 11-19 이전 PR 의 81% 가 2회 안에 끝났다. 3회째까지 간 PR 은 대부분 회차마다 새 반례가 나와 PR 을 쪼개야 끝났다. | #1184 Why |
| ADR-0030 은 주장 검증의 멈춤 조건을 「제로베이스 검토와 같다」로 두어 상한 3회를 따랐고, #1066 은 「같은 종류의 반례를 끝까지 나열」을 지시에 넣었다. | ADR-0030 · #1066 |

## 결정

1. **회차는 4분 안의 대조다.** 검증자는 주장 ↔ 구현 ↔ 테스트를 대조하고 행마다 구현을 되돌린 사본에서 테스트가 실패하는지 1회 본다. 퍼징 · 대량 입력 생성 · 차등 실험 같은 반례 탐색은 하지 않는다. 「같은 종류의 반례를 끝까지 나열」(#1066) 지시는 없앤다. 상한 4분은 11-19 이전 평균 3.0분에 여유 1분을 더한 값이고, 시험 회차(2.5~3.4분)도 그 안에 들었다.
2. **검증자는 주장 표의 행 × 판정 기준(1~4)마다 「봤다 · 일부 · 보지 못함」을 보고한다.** 「봤다」가 아닌 칸이 있는 행이 못 본 행이다. 회차 기록 줄에 못 본 행 수를 남긴다.
3. **못 본 행이 남은 회차는 통과가 아니다.** 그 행을 다시 보려고 회차를 더하지 않고, 그 행(주장)을 떼거나 PR 을 쪼갠 뒤 상한(결정 4) 안에서 남은 행으로 회차를 더한다. 최종 점검은 마지막 회차의 못 본 행 수가 없거나 0 이 아니면 통과로 적지 않는다.
4. **회차 상한은 리뷰 준비와 머지 준비를 합쳐 2회다.** 2회째에도 차단이 남으면 그 주장을 떼거나 PR 을 쪼갠다. 2회째 통과 뒤 머지 준비에서 동작 · 테스트가 바뀌어 남겨야 하면 3회째를 1회 실행하고, 결과와 무관하게 통과 기록 없이 사람에게 넘긴다(#1163 의 3회째 · 4회째를 2회째 · 3회째로 옮김). 최종 점검은 2회를 넘는 기록을 통과로 적지 않는다.
5. **상한은 제로베이스 검토와 연동하지 않는다.** ADR-0030 결정 2 의 멈춤 조건 중 「제로베이스 검토와 같음」(상한 3회)을 이 결정이 대체한다. 제로베이스 검토 자체의 상한 3회는 그대로다.

ADR-0030 에는 다시 열 조건 절이 없다. 대체 근거는 위 배경의 측정과 사용자 결정이다(ADR-0040 결정 6 · 7).

## 기각한 대안

| 대안 | 기각 이유 |
|------|-----------|
| 시간 제한만 건다. | 시험에서 차단 2건이 있던 행을 「봤다(일부)」로 적고 차단 0건을 내 통과로 기록됐다. 못 본 행을 통과에서 빼는 결정 3 없이는 시간 제한이 틀린 통과를 만든다. |
| 작성자가 반례 형태 목록을 미리 낸다. | 시험에서 결함 2건을 차단하지 못했고, 목록 작성에 검증과 비슷한 비용이 들었다. |
| 상한 3회를 유지한다. | 81% 가 2회 안에 끝났고, 3회째까지 간 PR 은 회차를 더해서가 아니라 PR 을 쪼개서 끝났다. 3회째는 비용만 더한다. |

## 다시 열 조건

| 관측 | 임계 | 그때 할 일 |
|------|------|------------|
| 실전 PR 의 주장 검증 회차 시간 | 10건에서 회차 중앙값이 4분 초과 | 상한 시간과 대조 범위(행 수 · 사본 실험)를 다시 잰다. |
| 머지 뒤 드러난 틀린 통과(주장 검증 통과 행의 결함) | 1건 | 그 행이 왜 「봤다」로 보고됐는지 보고, 대조 방식 또는 상한을 다시 정한다. |

크기 한계: 10건에서 틀린 통과가 0건이어도 틀린 통과 비율의 95% 상한은 약 30%다(3의 규칙, 3/10). 0/10 은 이 결정이 안전하다는 증거가 아니라 다시 열 조건에 닿지 않았다는 뜻이다.
