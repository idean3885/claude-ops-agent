# ADR-0044: 드래프트 PR 은 기본값이고, 사람이 선언한 레포만 생략한다 (방화벽식 디폴트 디나이)

- 상태: accepted
- 일시: 2026-11-20
- 관련: #1166, #876(드래프트 PR 강제), #977(어시스턴트 준비 완료 전환 차단), [ADR-0028](0028-merge-owner-follows-impact-scope.md)(레포 유형 선언)

## 배경

| 사실 | 출처 |
|------|------|
| 드래프트의 목적은 리뷰어에게 알림이 가기 전에 작성자가 변경분을 먼저 보는 것이다. | PR 가이드 「드래프트로 생성하고 작성자가 먼저 본다」 |
| 리뷰어가 없는 개인 레포에서는 지킬 대상이 없어, 사람의 준비 완료 전환 단계만 PR 마다 늘었다. 한 세션에서 개인 PR 네 건이 전환을 기다렸다. | 사용자 워크플로우 교정 (#1166) |
| 사내 레포는 드래프트가 필수다. | 사용자 결정 (#1166) |
| 레포 유형 선언은 사람만 쓰고, 선택 키 `allow` 로 갈래를 허용하는 선례가 있다(`git-default-push`). | docs/action-gate.md 「레포 유형」 |

## 결정

1. **드래프트 PR 은 모든 레포의 기본값이다.** 선언이 없거나 읽지 못하면 드래프트 필수다.
2. **레포 유형 선언의 `allow` 에 `skip-draft` 를 둔 레포만 드래프트를 생략한다.** 그 레포에서는 드래프트 없는 생성과 준비 완료 전환을 가드가 통과시킨다. 선언은 사람만 쓴다(기존 편집 차단).
3. **통과는 허용 목록으로만 정한다.** 훅 cwd 가 선언 레포이고, 명령 하나가 단독으로 `gh pr create`(알려진 옵션만) 또는 `gh pr ready <번호>` 이고, 이스케이프 · `$` · 백틱이 없을 때만 통과한다. 그 밖은 대상 레포를 알 수 없는 명령으로 보고 기본값을 따른다. 위험한 형태를 하나씩 막는 방식은 검증 두 회차에서 셸 표기(따옴표 · 묶음 플래그 · `GIT_DIR` · 변수)로 계속 우회됐다.

기본값을 드래프트로 두는 이유는 선언을 빠뜨렸을 때의 피해다. 개인 레포가 선언을 빠뜨리면 전환 단계 하나가 남을 뿐이다. 반대로 「기본은 생략, 사내 레포만 선언」으로 두면 선언을 빠뜨린 사내 레포의 PR 이 바로 준비 완료로 열려 리뷰어 알림이 먼저 간다. 이 알림은 되돌릴 수 없다.

## 다시 열 조건

| 관측 | 임계 | 그때 할 일 |
|------|------|------------|
| `skip-draft` 선언 레포에서 리뷰어 알림이 작성자 확인보다 먼저 간 사례 | 1건 | 그 레포의 선언을 사람에게 되묻고, 선언 기준(리뷰어 없음)을 문서에 더한다. |
| 선언 없는 개인 레포에서 전환 대기 요청 | 4주에 3건 | 선언 누락을 세션 시작 요약에 보인다. |
