# ADR-0047: 레슨 승인 묶음은 세션 마무리 때 상한 안에서 열고, 올릴 것이 없는 대기는 기계가 닫는다

- 상태: accepted
- 일시: 2026-11-23
- 관련: #1195, [ADR-0037](0037-lessons-judged-off-work-time-measured-by-accuracy.md)(결정 2 의 승인 시점 · 묶음 10건을 대체. 주 1회 고지는 보조로 남김), [ADR-0022](0022-lessons-keep-facts-procedures-tastes.md)(등재 조건), [ADR-0046](0046-claim-check-is-time-boxed-comparison.md)(시간 상한의 선례)

## 배경

| 사실 | 출처 |
|------|------|
| 승인 묶음은 사람이 /learn 을 부를 때만 열린다. 부르지 않는 운영에서 대기가 59세션 · 교정 217건까지 쌓였다. 유입은 하루 약 6세션이다. | judgments.jsonl 실측 (2026-11-23) |
| 대기 59세션 중 27세션은 교정이 0건이다. 승인할 것이 없는데 대기에 들어 있었다. | 같은 실측 |
| 지난 판정 기록에서 등재까지 간 교정은 약 30% 다. 나머지는 등재 조건(ADR-0022) 미달이라 사람이 봐도 기각으로 끝난다. | 볼트 판정 기록 |
| 상한 없는 탐색은 비용을 키웠고 단순한 상한은 바로 효과가 났다. 주장 검증 회차가 3분에서 10\~36분으로 늘었다가 4분 상한으로 돌아왔다. | ADR-0046 |
| 선행 연구는 교훈 목록을 고정된 소수 동작(ExpeL), 증분 수정(ACE), 시간 감쇠와 고정 예산(에이전트 기억 연구)으로 관리한다. | #1195 조사 |

목적은 일을 잘하는 것이다. 레슨 승인은 수단이라, 사람의 주의를 쓰는 양에 상한을 두고 그 밖은 기계가 닫는다 (작업 원칙 「위계」).

## 결정

1. **승인 묶음은 세션 마무리 신호에서 연다.** 마무리 훅이 올릴 대기가 있을 때만 한 줄을 낸다. 사람이 기억해서 부르지 않아도 된다. 마무리는 사람이 자리에 있는 시점이다. 세션 시작 때의 주 1회 고지(ADR-0037 결정 2)는 마무리를 거르는 운영의 보조로 남긴다.
2. **묶음은 5건 · 3분이 상한이다.** 남은 건은 다음 마무리로 넘긴다. 후보 유입(하루 약 2건)보다 상한이 커서, 하루 한 번 마무리하면 쌓이지 않는다.
   - 수정(#1209): 「5건」의 단위는 세션이 아니라 등재 후보다. 세션 단위로 세면 교정이 많은 세션 하나가 후보 수십 개를 끌고 와(실측 묶음 하나에 후보 40개) 3분 안에 열지 못하고 만료됐다. 같은 자산이 재발한 후보를 먼저 올리고, 세션은 남은 후보가 없을 때 검토 완료가 된다.
3. **판정이 교정마다 등재 조건을 함께 낸다.** 같은 판정 호출의 필드 하나(`admit`: 환경 사실 · 되돌릴 수 없는 절차 · 추측할 수 없는 취향 · 없음)다. 판별기를 따로 만들지 않는다.
4. **올릴 것이 없는 대기는 기계가 닫는다.** 교정이 없거나 새 교정이 모두 「없음」이면 기각, 7일이 지나면 만료다(#1215 에서 14일 → 7일. 진짜 교훈은 재발해 새 후보로 다시 올라오고, 일주일이 지나면 사람도 그 세션의 맥락을 기억하기 어렵다. 세션 시작 고지 주기와 같다). 등재 조건 판정이 없는 옛 행은 후보로 둔다. 자동 등재는 여전히 없다.
5. **보고는 자동 기각 · 만료 건수를 보인다.** 새 지표는 두지 않는다.

## 기각한 대안

| 대안 | 기각 이유 |
|------|-----------|
| 지금처럼 /learn 을 손으로 부른다 | 부르지 않으면 대기가 끝없이 쌓인다. |
| 마무리마다 대기를 모두 연다 | 마무리가 레슨 처리로 바뀐다. 수단이 목적의 시간을 쓴다. |
| 주 1회 정해진 날 몰아서 연다 | 한 번에 30건 이상이 되어 그날 세션을 통째로 쓴다. |
| 기각 판단만 하는 판별기를 따로 둔다 | 정밀도를 쫓는 판별기는 후속 수정이 이어진다(전문가 경유 지표: 4일에 후속 이슈 3개). 판정 호출의 필드 하나로 충분하다. |
| 쌓인 대기를 모두 다시 판정해 등재 조건을 채운다 | 세션당 약 0.25달러가 든다. 교정 0건 닫기와 만료로 비용 없이 줄어든다. |
| 외부 스킬 스택(pstack)을 들인다 | 라우팅 훅 · 플레이북이 이 플러그인과 같은 자리를 겹쳐 가진다. Claude 이식판에는 자동 학습이 없고 벤치마크가 없다. |

ADR-0037 의 다시 판정할 조건은 판정 지표의 신뢰 · 비용 · 판단 실수 추이를 다루고, 승인 시점은 다루지 않는다. 대체 근거는 위 배경의 측정과 사용자 결정이다(ADR-0040 결정 6 · 7).

## 결과

- 사람의 몫은 마무리 때 5건 · 3분 안이다.
- 포기하는 것: 만료로 닫힌 후보 중 등재했어야 할 것. 만료 건수를 보고 상한을 조정한다.
- 판정 입력은 그대로이고 출력 필드가 하나 늘어난다.

## 다시 열 조건

- 2주 시범에서 기한 만료가 자동 기각을 제외하고 남은 후보의 30% 를 넘으면 상한을 늘리거나 만료 기한을 늘린다.
- 마무리 레슨 처리가 3분을 넘는 일이 2주에 3회 이상이면 묶음 상한을 줄인다.
- 사람 표본에서 「없음」으로 기각된 교정 중 등재 조건에 드는 것이 2건 이상 나오면 자동 기각을 멈추고 후보로 올린다.
