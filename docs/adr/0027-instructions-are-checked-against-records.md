# ADR-0027: 지시는 기록과 대조하고, ADR 은 뒤집거나 대안을 남길 때만 쓴다

- 상태: accepted
- 일시: 2026-10-13
- 관련: 이슈 #675, ADR-0024(자산에서 시작한다)

## 배경

지시는 사람과 시점에 따라 달라진다. 같은 사람도 생각이 바뀌고, 앞서 정한 것을 놓친다. 새 지시를 과거 기록과 대조하지 않으면 방향이 흔들려도 알아채지 못한다.

반대로 지시마다 ADR 을 쓰면 기록이 무거워진다. 하루에 ADR 이 3건 늘어난 날이 있었다. 결정 하나에 문서 하나를 요구하면 결정이 느려진다.

## 결정

1. 방식 · 규칙을 정하는 지시가 오면 같은 주제의 기존 기록(ADR · 규칙 · 스킬 · 이슈)을 먼저 찾는다. 이전 · 지금 · 바뀐 점을 밝힌 뒤 진행한다.
2. 바뀐 것이 없으면 과거 지시를 기준으로 간다. 바뀐 것이 있으면 그 점만 보완한다.
3. 지시는 그 지시가 다스리는 문서(스킬 · 가이드 · 규칙)에 한 줄로 남긴다.
4. ADR 은 기존 결정을 뒤집거나, 기각한 대안을 남겨야 할 때만 쓴다.

실행 자리는 레포 `CLAUDE.md` 수정 플로우 「이슈 전」 표와 flow 이슈 가이드의 생성 단계다.

## 기각한 대안

| 안 | 기각 이유 |
|----|-----------|
| 지시마다 ADR 을 쓴다. | 결정마다 문서가 하나씩 늘어 의사결정이 무거워진다. |
| 메모리에 지시를 남긴다. | 그 기계에만 있고 검토 없이 다시 읽힌다 (ADR-0026). |
| 기록하지 않고 매번 새로 판단한다. | 지시가 흔들려도 알아채지 못한다. |

## 롤백 조건

대조 단계가 이슈마다 빈 「이전 기록 없음」 줄만 남기는 일이 열 건 이어지면, 대조 대상을 ADR 과 규칙 문서로 좁힌다.
