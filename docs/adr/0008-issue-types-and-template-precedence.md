# ADR-0008: 판정 목적 이슈를 유형으로 세우고 트래커 템플릿에 섹션 집합을 넘긴다

- 상태: accepted
- 일시: 2026-08-27
- 관련: 이슈 #348 · #351 · #354 · #356, ADR-0002(표기 선언의 소관)

## 배경

이슈 익스텐션은 이슈를 셋으로 나눠 왔다. 버그(ISS1)·기능·운영(ISS5)·보고(ISS6). 이 분류에서 네 가지가 걸렸다.

| 걸린 것 | 증상 |
|---------|------|
| 외부 조건이 확정된 뒤 영향을 판정하는 이슈 | 셋 중 어디에도 맞지 않는다. ISS5 를 적용하면 판정 근거가 사라지고 ISS6 은 결론을 뒤에 둔다 |
| 조직 표준 템플릿이 요구하는 섹션 | ISS5 합격선이 그 섹션을 지우게 만든다 |
| `profiles.md` 합격선 표 | 버그·기능 두 행만 있어 ISS6 을 만나면 적용할 합격선이 없다 |
| 제목과 본문의 역할 분담 | ISS2 가 정하지 않아 제목에 있는 정보가 본문 첫 줄에 다시 나온다 |

## 결정

### 1. ISS7 판정 목적 이슈를 세운다

외부 조건이 확정된 뒤 「우리 구조에서 무엇이 달라지는가」를 판정하는 이슈다. 구조는 판정 → 확정된 외부 조건 → 달라지는 것 → 설계 기준 → 남은 논의.

**ISS6 과 방향이 반대다.** ISS6 은 측정 과정의 타당성이 검토 대상이라 발견 순서를 따르고, ISS7 은 결론이 검토 대상이라 판정을 첫 절에 둔다. 근거를 앞에 쌓고 결론을 뒤에 두면 재판정 때 무엇이 바뀌었는지 대조할 지점이 없다.

「달라지는 것」을 표로 고정한 이유도 재판정이다. 이 유형은 외부 조건이 바뀔 때마다 같은 구조로 다시 판정하고 표만 교체하는 형태로 쓰인다. 산문으로 적으면 다음 판정에서 무엇을 교체할지 정해지지 않는다.

설계 기준과 달라지는 것을 나눈다. 기준은 조건이 바뀌어도 남고 표는 교체된다.

### 2. 트래커 표준 템플릿이 섹션 집합을 정한다

조직이 템플릿으로 구현 방안·할 일·검증 섹션을 요구하면 그 섹션을 남긴다. **섹션 집합은 템플릿이 정하고, 각 섹션에 무엇을 적을지는 익스텐션이 정한다.** 표기 선언이 기본값을 대체하는 것과 같은 순서다(ADR-0002).

도메인 추상화 금지 항목은 템플릿이 요구한 섹션 안에서도 계속 적용한다. 섹션을 남기는 것과 그 안에 사내 식별자를 적는 것은 다른 문제다.

「PR 로 미룬다」는 이슈와 PR 이 다른 범위일 때 성립한다. 하위 태스크를 커밋 1건과 1:1 로 잡는 컨벤션에서는 범위가 같아 미루는 것이 아니라 지우는 것이 되므로, 그 경우 초과분을 이슈에 둔다.

### 3. 제목의 명사를 지워 보고 판정한다

**본문에서 제목의 명사를 지웠을 때 뜻이 유지되면 그 명사는 중복이다.** 지웠을 때 뜻이 무너지면 제목이 그 정보를 담지 못한 것이므로 본문을 남기지 않고 제목을 고친다.

판정을 문장 하나로 준 이유는 이 교정이 감으로 반복돼 왔기 때문이다. 한 세션에서 같은 지적이 두 번 나왔고 둘 다 제목에 있는 단어를 본문에서 걷는 교정이었다.

### 4. 합격선 표에 유형별 행을 채운다

`profiles.md` 합격선 표에 보고·판정·공통 세 행을 더한다. 검증하는 쪽은 이 표를 기준으로 판정하므로, 행이 없으면 인접 유형의 합격선을 대신 적용하게 된다. ISS6 본문이 그 적용을 명시적으로 막고 있었는데도 표에는 근거가 없었다.

## 기각한 대안

| 대안 | 기각 이유 |
|------|-----------|
| 판정 이슈를 ISS6 의 변종으로 둔다 | 결론의 위치가 반대다. 같은 유형 안에서 순서를 뒤집는 예외를 두면 판정할 수 없다 |
| 제목 중복을 새 번호(ISS8)로 둔다 | 제목 규칙이 둘로 나뉜다. ISS2 를 읽고 지나가면 중복 판정을 만나지 못한다 |
| 템플릿 충돌을 `profiles.md` 적용 강도 표에서 다룬다 | 그 표는 base 규칙의 강도를 정하는 자리다. 섹션 집합의 소관은 익스텐션 본문이 정할 문제다 |
| 템플릿보다 익스텐션을 우선한다 | 조직이 합의한 섹션을 지우게 된다. 리뷰 절차가 그 섹션을 읽는 전제로 서 있다 |

## 다시 열어야 하는 조건

| 조건 | 다시 볼 것 |
|------|-----------|
| ISS7 로 판정한 이슈가 재판정 없이 닫히는 사례가 이어진다 | 재판정 전제로 만든 고정 포맷이 값을 하는지 |
| 템플릿이 요구한 섹션에서 도메인 추상화 위반이 반복된다 | 섹션별 금지 항목을 따로 둘지 |
| 유형이 여덟 개를 넘는다 | 분류 기준 자체를 다시 볼 시점 |
