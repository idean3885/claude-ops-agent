# ADR-0045: 개념 설명은 정식 정의 · 업계 통용 비유 · 완성 문장으로 하고, 기술 커뮤니케이션 원칙에 TC9 를 더한다

- 상태: accepted
- 일시: 2026-11-20
- 관련: #1168, [ADR-0035](0035-writing-assets-unified-as-tech-comm.md)(결정 2 「원칙은 여덟 개다」를 대체)

## 배경

| 사실 | 출처 |
|------|------|
| 개념은 외우는 것이 아니라, 이미 널리 아는 패턴에 걸면 바로 이해된다. 정식 정의 · 구체 예시 · 완성 문장에 더해 업계에서 통용되는 비유가 필요하다. | 사용자 결정 (#1168) |
| 전역 지침 「설명 수준」은 비유를 3단계(엑스트라)에만 두고 종류를 제한하지 않았다. 드래프트 생략을 「현관문 자동 잠금」으로 설명했고, 사용자가 「화이트리스트 스타일」 수준의 전문성을 요구해 「방화벽식 디폴트 디나이」로 바꿨다. | 사용자 워크플로우 교정 (#1168) |
| ADR-0035 결정 2 는 원칙을 여덟 개(TC1~TC8)로 정했다. | ADR-0035 |

## 결정

1. **개념 설명 1단계는 정식 정의 + 업계 통용 비유 한 줄이다.** 비유는 개발 업계에서 이름이 붙은 패턴(디폴트 디나이 · 화이트리스트 · 서킷 브레이커 같은 것)만 쓰고, 맞는 패턴이 없으면 쓰지 않는다. 생활 비유는 전문성이 없어 그대로 말할 수 없다.
2. **2단계는 구체 예시 + 그대로 말할 수 있는 완성 문장이다.** 3단계는 대조와 비유가 깨지는 지점이다. 한 턴에 한 단계는 그대로다.
3. **기술 커뮤니케이션 원칙은 아홉 개다(TC1~TC9).** TC9 는 개념 설명이다. ADR-0035 결정 2 의 「여덟 개」를 대체한다.

ADR-0035 의 다시 열 조건 둘(lint 와 같은 지적 반복, 시범 교정 수 불변)은 이 변경과 관계가 없다. 충족된 조건 없이 대체하는 이유는 사용자 결정이다(ADR-0040 결정 6 · 7). 원칙을 하나 더하는 것이고 기존 여덟 개는 바뀌지 않는다.

| 관측 | 임계 | 그때 할 일 |
