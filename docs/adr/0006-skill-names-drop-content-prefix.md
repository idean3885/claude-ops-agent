# ADR-0006: 스킬 이름에서 content- 접두를 걷는다

- 상태: accepted
- 일시: 2026-08-27
- 관련: ADR-0005(계획 게이트가 수정도 덮는다), ADR-0003(스코프 라우터 기각 — 이름 충돌 판정)

## 배경

`content-write` 는 기술 문서·이슈·설계 문서·리드미에 모두 쓰는 스킬이었는데 이름이 「콘텐츠」로 범위를 좁혀 불렀다. 다루는 대상이 그 말을 넘어섰다.

ADR-0005 에서 단계 어휘를 계획 → 초고 → 퇴고 → 교정으로 고정하고 그 단어들을 트리거로 등록했다. 그 뒤 부르는 말과 파일 경로가 다른 층을 가리키게 됐다. 사람은 「교정」이라고 부르는데 경로는 `skills/content-verify/` 였다.

이름을 미룰 근거로 「내부 정리」를 들었으나 그 판단의 비용을 재지 않았다. 실측하니 이 레포 안에서 고칠 파일이 열일곱, 외부 소비자가 일곱, 외부 플러그인 하드코딩이 0 이었다.

## 결정

### 1. 세 스킬을 개명한다

| 전 | 후 | 근거 |
|----|----|------|
| `content-write` | `write` | 대상이 콘텐츠로 좁혀지지 않는다 |
| `content-verify` | `lint` | 기계 대조 단계다. 사람이 부르는 말은 「교정」이고 트리거로 남긴다 |
| `content-publish` | `publish` | 접두를 하나만 남기면 규칙성이 흐려진다 |

### 2. 부르는 말과 디렉토리 이름을 다른 층으로 둔다

트리거는 한국어 단계 이름이고 디렉토리 이름은 부르는 대상이 아니다. 그래서 `lint` 라는 영어 이름과 「교정」이라는 트리거가 같이 있어도 충돌이 아니다.

`lint` 의 트리거에서 「윤문」을 제외했다. ADR-0005 결정 4 가 사람이 부르는 자리에서 제외한 말이므로 트리거에 남으면 결정과 어긋난다.

### 3. hook 의 마커 파일은 예전 이름도 읽는다

`hooks/content-verify-posttool.sh` → `hooks/lint-posttool.sh` 로 바꾸고, opt-in 마커는 `.ops-agent/lint.json` 을 우선 읽되 `.ops-agent/content-verify.json` 도 계속 읽는다.

**이 hook 은 마커가 없으면 조용히 종료한다.** 이름만 바꾸면 소비 레포에서 아무 신호 없이 점검이 꺼진다. 실패가 보이지 않는 경로는 호환을 남긴다.

### 4. 이력 문서는 고치지 않는다

`CHANGELOG.md` 와 기존 ADR 의 `content-*` 표기는 그대로 둔다. 그 시점에는 그 이름이 정본이었다. 이력을 현재 이름으로 덮으면 언제 무엇이 바뀌었는지 읽을 수 없게 된다.

### 5. 사내 어댑터의 동명 스킬을 가리키는 줄은 유지한다

`base/ai-tells.md` 와 `extensions/wiki.md` 에는 외부 어댑터가 가진 `content-write` 를 가리키는 줄이 있다. 이 레포의 개명과 무관한 다른 레포의 이름이므로 바꾸지 않는다. 그 레포가 개명하면 그때 따라간다.

## 기각한 대안

| 대안 | 기각 이유 |
|------|-----------|
| `write` 대신 `writing` | 다른 스킬(`flow`·`setup`·`learn`·`publish`)이 전부 동사 원형이다. 하나만 명사형이면 규칙성이 흐려진다 |
| `lint` 대신 `proofread` | 영어 이름을 길게 만들면서 얻는 것이 없다. 사람이 부르는 말은 이미 한국어 「교정」이다 |
| 마커 파일 이름도 새 이름만 읽는다 | 실패가 보이지 않는다. 점검이 꺼진 것을 알 방법이 없다 |
| 이름을 그대로 두고 문서만 고친다 | 부르는 말과 경로가 계속 어긋난다. 미룬 판단의 비용이 실측으로 작게 나왔다 |

## 대가

`skillUsage` 카운터의 키가 새로 시작된다. 개명 전 호출 이력은 옛 키에 남고 합산되지 않는다.

외부 소비자가 `ops-agent:content-write` 로 호출하던 경로는 끊긴다. 같은 배치에서 소비자 참조를 갱신한다.

## 다시 열어야 하는 조건

| 조건 | 다시 볼 것 |
|------|-----------|
| `lint` 가 교정 외 단계까지 맡게 된다 | 이름이 다시 범위를 좁히는지 |
| 예전 마커 이름을 쓰는 레포가 0 이 된다 | 호환 갈래 제거 |
