# 부트스트랩

스킬이 자기 `requires:` 로 선언한 외부 의존을 모아 상태를 보고한다. 설치는 사용자가 실행한다.

## 목록을 여기 두지 않는 이유

이 스킬은 무엇이 필요한지 알지 못한다. 각 스킬이 선언하고 이것은 읽는다.

목록을 한 곳에 모으면 스킬이 늘 때마다 그 자리가 낡는다. 선언이 스킬 파일과 함께 들어오면 갱신이 따로 필요하지 않다.

## `requires:` 선언

스킬 프론트매터에 적는다. 없으면 의존이 없는 스킬이다.

```yaml
requires:
  - kind: marketplace
    name: <마켓플레이스 이름>
    check: claude plugin marketplace list
    install: claude plugin marketplace add <저장소 URL 또는 owner/repo>
  - kind: plugin
    name: <플러그인 이름>@<마켓플레이스 이름>
    check: claude plugin list
    install: claude plugin install <플러그인 이름>@<마켓플레이스 이름>
  - kind: command
    name: <실행 파일 이름>
    check: command -v <실행 파일 이름>
    install: <설치 명령>
    why: <이 스킬의 어느 단계가 이것을 쓰는가>
```

| 필드 | 담는 것 |
|------|---------|
| `kind` | `marketplace` · `plugin` · `command` 중 하나 |
| `name` | 확인과 설치에 쓰는 식별자 |
| `check` | 존재를 판별하는 명령. 종료 코드가 0 이면 있다 |
| `install` | 사용자에게 건넬 명령 |
| `why` | 어느 단계가 쓰는지. 미충족 보고에 함께 낸다 |
| `version` | 선택. 그 값이 실제로 동작을 바꿀 때만 적는다 |

`marketplace` 를 `plugin` 보다 먼저 적는다. 마켓플레이스가 등록돼 있지 않으면 그 안의 플러그인 이름이 해석되지 않는다.

## 진입 게이트

**의존이 빠진 스킬은 진입하지 않는다.**

| 상태 | 동작 |
|------|------|
| 전부 충족 | 그대로 진행 |
| 하나라도 미충족 | 그 자리에서 멈추고 미충족 보고를 낸다 |
| `check` 실행 자체가 실패 | 미충족으로 다룬다. 확인하지 못한 것을 있는 것으로 두지 않는다 |

미설치 상태에서 절반만 도는 것은 없는 것보다 나쁘다. 어디까지 됐는지 사용자가 판별할 수 없고, 그 결과가 다음 판단의 근거가 된다.

## 미충족 보고

| 항목 | 내용 |
|------|------|
| 무엇이 빠졌나 | `kind` 와 `name` |
| 어디에 쓰이나 | `why` 그대로 |
| 어떻게 넣나 | `install` 명령 그대로. 사용자가 실행한다 |

**설치를 실행하지 않는다.** 외부 플러그인을 들이는 것은 다른 사람이 쓴 지시문을 세션에 로드하는 행위다. 그 판정은 사람이 한다.

**설치를 요구하지도 않는다.** 그 기능이 필요 없는 사용자에게 의존을 전제로 걸지 않는다. 멈춘 자리에서 사용자가 설치할지 그 스킬을 쓰지 않을지 정한다.

## 상태 보고

`부트스트랩` 으로 직접 부르면 전체 스킬의 의존을 훑어 표로 낸다.

| 상태 | 뜻 |
|------|-----|
| 충족 | `check` 가 0 을 돌려줬다 |
| 빠짐 | `check` 가 0 이 아닌 값을 돌려줬다 |
| 확인 불가 | `check` 명령 자체를 실행할 수 없었다 |
| 낡음 | `version` 선언이 있고 설치된 값이 그 제약 밖이다 |

빠진 항목이 여럿이면 설치 명령을 한 덩어리로 묶어 낸다. 한 줄씩 왕복하면 그 도구를 직접 쓰는 편이 빨라진다.

## 하지 않는 것

- `plugin.json` 의 `dependencies` 에 도메인 플러그인을 걸기. 이 레포를 쓰는 모든 프로젝트에 그것이 따라온다
- 설치 명령을 어시스턴트가 실행하기
- 확인을 통과시키기 위한 예외 목록 만들기. 확인이 틀렸으면 `check` 를 고친다
- 의존이 없는 스킬에 빈 `requires:` 를 적기
